🛠️ Bantuan & Setup

Panduan singkat menghubungkan dashboard ini dengan Google Spreadsheet data pendaftar.

1️⃣ Siapkan Google Apps Script

  1. Buka script.google.com → New project.
  2. Tempel seluruh isi file Code.gs dari folder ini.
  3. Pastikan SHEET_ID dan SHEET_NAME sesuai spreadsheet pendaftar.

2️⃣ Deploy sebagai Web App

  1. Deploy → New deployment → ⚙️ Web app.
  2. Execute as: Me
  3. Who has access: Anyone
  4. Salin URL berakhiran /exec.

3️⃣ Hubungkan ke Dashboard

  1. Buka script.js.
  2. Tempel URL tadi di bagian paling atas:
const GAS_WEB_APP_URL =
  "https://script.google.com/…/exec";

4️⃣ Selesai & Pantau

  1. Deploy ulang (New version) setiap kali mengubah Code.gs.
  2. Dashboard memuat ulang otomatis sesuai pengaturan Auto di pojok kanan atas.
  3. Gunakan Export CSV untuk unduh rekap data.
