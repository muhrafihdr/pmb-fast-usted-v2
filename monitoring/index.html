🛠️ Bantuan & Setup

Dashboard membaca data langsung dari Google Spreadsheet. Ada 2 cara — pilih salah satu.

✅ Cara A — Spreadsheet Publik (untuk data PMB)

  1. Buka spreadsheet data pendaftar di Google Sheets.
  2. Klik tombol Share / Bagikan (kanan atas).
  3. Ubah akses menjadi Anyone with the link → Viewer.
  4. Data PMB otomatis tampil di Dashboard & Data Pendaftar.

⚠️ Semua orang bisa melihat isi spreadsheet (termasuk NIK). Hanya lakukan jika sudah siap, atau gunakan Cara B.

🔒 Cara B — Apps Script (untuk Pencatatan Kegiatan)

Fitur Pencatatan Kegiatan menyimpan data baru ke spreadsheet "MONITORING FAST TERBARU" (sheet Monitoring_FAST) melalui backend Apps Script. Tanpa backend, data tersimpan lokal di browser.

  1. Buka script.google.com → New project.
  2. Tempel seluruh isi Code.gs dari folder ini.
  3. Deploy → New deployment → ⚙️ Web app.
  4. Execute as: Me  •  Who has access: Anyone
  5. Salin URL /exec → tempel di DATA_SOURCE.gasUrl pada script.js.

💡 Data lama (35 kegiatan) sudah otomatis terbaca dari spreadsheet yang sama — tanpa impor terpisah.

4️⃣ Selesai & Pantau

  1. Dashboard memuat ulang otomatis sesuai pengaturan Auto di pojok kanan atas.
  2. Gunakan Export CSV untuk unduh rekap data.
  3. Data baru dari formulir PMB muncul otomatis dalam beberapa saat.

⚙️ Kustomisasi

  1. Ganti DATA_SOURCE.sheetId di script.js jika memakai spreadsheet lain.
  2. Atur kolom default tabel di DEFAULT_COLS.
  3. Ubah warna tema di :root pada style.css.
